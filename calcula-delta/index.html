Calcula Delta

Calcule o discriminante (Δ) de uma equação do segundo grau.

i

Sobre a equação

Informe uma equação dos segundo grau no formato geral:

ax2 + bx + c = 0

Exemplos válidos: 2x2 + 3x - 5 = 0, -x2 + 4x + 4 = 0, 5x2 - 7x + 1 = 0.

✎

Equadação do segundo grau

Dica: espaços são opcionais. Use o ^ para representar o expoente. Exemplo x^2
