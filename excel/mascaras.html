Formatação Personalizada no Excel como Máscara de Dados

A formatação personalizada do Excel permite controlar a forma como os dados são exibidos, sem modificar o valor original armazenado na célula.

1. Conceito de Máscara

Uma máscara funciona como uma camada visual aplicada ao conteúdo. Ela organiza números, códigos e informações para melhorar leitura e padronização.

Valor armazenado: 12345678901
Máscara: 000"."000"."000"-"00
Resultado: 123.456.789-01

2. Símbolo 0 - Número Obrigatório

O símbolo 0 força a exibição de um número naquela posição. Caso não exista valor, o Excel completa com zero.

00000

Entrada: 125
Saída: 00125

Aplicações reais:

  • Código de produtos
  • Matrículas
  • Protocolos
  • Número de clientes

3. Símbolo # - Número Opcional

O símbolo # exibe números somente quando eles existem. Ele não adiciona zeros extras.

###.###

5000 → 5.000
50 → 50

Aplicações:

  • Relatórios financeiros
  • Quantidade de produtos
  • Indicadores

4. Diferença entre 0 e #

Formato Valor Resultado
00000 25 00025
##### 25 25

5. Uso das Aspas ""

As aspas adicionam textos fixos junto ao valor.

0 "kg"

Entrada: 25
Resultado: 25 kg

Aplicações: Estoque, peso, medidas e produtos.

6. Símbolo @ - Texto

Representa qualquer texto digitado pelo usuário.

"Cliente: "@

Entrada: João Silva
Resultado: Cliente: João Silva

7. Exemplos Profissionais

  • Estoque: 000000 → 000125
  • Peso: 0,00 "kg" → 12,50 kg
  • Percentual: 0,00% → 15,50%
  • Moeda: R$ #.##0,00 → R$ 25.450,90

8. Resumo dos Símbolos

Símbolo Função
0Número obrigatório
#Número opcional
.Separador de milhares
,Casas decimais
" "Texto fixo

%Percentual

Conclusão

A formatação personalizada transforma planilhas comuns em documentos profissionais, permitindo padronização de dados em sistemas administrativos, financeiros, estoques e relatórios.
